# ToDo App

Приложение-список задач на Kotlin и Jetpack Compose. Учебный проект, **в разработке**.

## Что уже умеет
- Добавлять задачи через поле ввода (пустые не добавляются)
- Отмечать задачи выполненными, выполненные зачёркиваются
- Удалять задачи
- Сохранять состояние при повороте экрана (ViewModel и rememberSaveable)
- Второй экран с подробностями задачи (Navigation Compose)
